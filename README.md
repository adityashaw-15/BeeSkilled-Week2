# BeeSkilled Web Development Internship

## Week 2 – CSS & Basic JavaScript

**Project:** Digital Clock Web Application

**Developed by:** Aditya Kumar Shaw

### Project Description

A simple, responsive digital clock developed using HTML, CSS, and JavaScript as part of the BeeSkilled Web Development Internship – Week 2 assignment.

The application displays the current time and date and updates automatically every second.

### Features

- Live digital clock displaying time in HH:MM:SS format
- Automatic time updates every second
- Current date and day display
- Modern gradient background
- Responsive design for desktop and mobile devices
- Hover animation effects
- Clean and user-friendly interface

### Technologies Used

- **HTML5:** Structure of the webpage
- **CSS3:** Styling, layout, and animations
- **JavaScript:** Real-time clock functionality and date display

### How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in any modern web browser.
5. The digital clock will start automatically.
